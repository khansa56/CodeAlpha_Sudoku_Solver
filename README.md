# 🧩 Code Alpha Internship - Task 3
## 🎯 Sudoku Solver (C++)

### 📝 Description
A C++ based Sudoku Solver that uses backtracking algorithm to solve any valid Sudoku puzzle.

### ✨ Features
✅ 9x9 grid representation using 2D array
✅ Backtracking algorithm implementation
✅ Row, column, and 3x3 subgrid validation
✅ Recursive solving approach
✅ Beautiful formatted output
✅ Predefined puzzles for testing
✅ Input validation

### 🚀 How to Run
```bash
g++ sudoku_solver.cpp -o sudoku
./sudoku
